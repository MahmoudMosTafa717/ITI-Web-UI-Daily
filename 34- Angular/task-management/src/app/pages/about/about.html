About Task Manager

A modern Angular application built to demonstrate best practices

🏗️ Architecture

Built with Angular's standalone component architecture, this app showcases modular design with lazy-loaded feature modules, route guards, and a clean separation of concerns.

🔄 Lifecycle Hooks

Demonstrates ngOnInit for timer initialization, ngOnChanges for receiving new tasks via @Input, and ngOnDestroy for cleanup with component-closed notifications.

📝 Forms

Features both Template-driven Forms (Login) and Reactive Forms (Signup) with full validation, error messages, and form state management.

🔐 Authentication

Local authentication using localStorage with Auth Guards for protected routes and Guest Guards for public-only routes like Login and Signup.

⚡ Lazy Loading

The Auth and Tasks modules are lazy-loaded using loadChildren for optimal performance, loading code only when needed.

🎯 Key Concepts

  • @Input / @Output decorators
  • @switch control flow
  • Route guards (CanActivate)
  • Services & dependency injection
  • ChangeDetectorRef
  • :host {{ '{' }} display: contents {{ '}' }}
